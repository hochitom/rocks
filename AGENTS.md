## Agent skills

### Issue tracker

Issues und Specs liegen lokal als Markdown unter `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Standard-Vokabular (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) als `Status:`-Zeile in jeder Ticket-Datei. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: eine `CONTEXT.md` und `docs/adr/` im Hauptverzeichnis. See `docs/agents/domain.md`.
